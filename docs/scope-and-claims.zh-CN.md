# 范围与宣称边界

本文档明确说明本仓库今天**确实做了什么**、**没有做什么**。
其存在的目的，是让任何读者与任何自动化系统都不会把「意图」误认为「已实现的能力」。
如果代码与本文档不一致，则代码是错误的，本文档是规范。

## 已实现的内容

| 能力 | 说明 |
| --- | --- |
| `qiyan help` | 向 stdout 打印用法说明，退出码 0 |
| `qiyan version` | 打印版本与构建标识，退出码 0 |
| 未知命令 | 向 stderr 打印错误、打印用法，退出码 2 |
| 构建 | 仅依赖标准库的 Go 模块，`go build ./cmd/qiyan` |
| 测试 | 覆盖命令行行为的单元测试，`go test ./...` |
| CI | 在 Linux、Windows、macOS 上执行 build、vet、gofmt 与 test |
| 发布演练 | 按需生成带构建来源证明的测试产物 |

以上就是全部。不存在其他行为。

## 未实现的内容

以下均为**目标**，在本仓库中一概不存在：

- 任何形式的扫描、探测或发现；
- 证据模型，以及任何证据的采集或存储；
- 爆炸半径测绘或图结构构建；
- 任何从真实系统推导出的「行动面」概念；
- 任何 Agent 集成、插件、适配器或扩展点；
- 任何输出格式、报告或机器可读结果；
- 任何网络访问 —— 程序不打开任何套接字；
- 除读取自身参数之外的任何文件系统遍历。

`qiyan` 目前只接受两个动词并打印文本，除写入 stdout 与 stderr 外不执行任何 I/O。

## 本项目不作以下宣称

- **不**宣称能够发现、检测、阻止或评估漏洞。
- **不**宣称任何安全、隐私或合规属性 —— 目前并不具备可宣称的能力。
- **不**宣称与任何其他工具、格式或标准兼容。
- **不**宣称项目可用于生产、已稳定或适用于任何用途。此处一切尚未稳定，尚无任何版本发布。
- **不**宣称 CI 变绿即代表其输出可信 —— 目前根本没有输出可供信任。

## 关于供应链的精确表述

- 发布演练中的 **SHA-256 摘要**是完整性校验值，
  **不是**数字签名，其本身不提供任何真实性保证。
  CI 本身不产生摘要 —— 它不发布任何可供摘要的产物。
- **GitHub 构建来源证明（artifact attestation）**是由该工作流运行的
  GitHub Actions 身份签署的构建来源记录。
  它**不是**企业级签名或具有法律效力的签名；
  它证明的是产物**如何被构建**，而不是它**可以安全运行**。
- 本构建的「可重现」仅指只使用 Go 标准库、不下载任何模块；
  不作更强的可重现性宣称。
